# Authored actor models

Eight actor types for the Canvas 3D training field:
Tanya, Apocalypse, Allied construction yard, Soviet nuclear reactor,
Soviet ore refinery, War Miner, Rocketeer and Giant Squid.

`<asset>/GLB + provenance -> tools/environment/canvas3d/catalog.js`

Tanya, Rocketeer and Squid have skeletal clips. The other models are static;
rigid-body scene feedback is not mechanical animation. Four recovered outputs
are indexed by hash in `recovery-inventory.json`; see each directory README.
High-resolution masters remain outside Git. Recovery restores only existing
paid tasks, using checked master hashes and the recorded optimization recipe.
