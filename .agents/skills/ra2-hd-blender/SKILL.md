# RA2 高清素材 → 游戏用 GLB → 按需生成 Canvas 精灵

默认目标是游戏实际可用的轻量素材，而非把服务返回的最高面数模型直接作为交付档。已有模型时直接从优化开始，不重新生成付费任务。保留 `ra2-hd-blender` 名称兼容已有引用；不默认通过 Blender 手工重建。

## 1. 从低清原图生成参考

- 确认资产身份和实际源图；必要时读 [原素材与参考提示词](references/source-to-hd.md) 提取正确的层、帧和调色板。保留原分辨率文件。
- 默认使用内置 ImageGen，并遵循当前环境的 imagegen skill。以低清原图作为图片输入，生成一张适合 Meshy 的清楚参考；已有用户认可图片时直接进入下一步。
- 使用参考文档的通用模板，替换单位身份、已观察到的结构与材质。建筑、兵种、车辆、船只不继承其他资产特有的屋顶、起重机或地基。
- 优先保持原图的风格、轮廓、组件数量、比例与配色，完整物体及原视角、简洁背景。不默认追加细节或多个候选。
- 区分源图分辨率、输出尺寸与 API 的 `quality=low`。内置 ImageGen 只使用实际暴露的参数；记录真实调用方式，不虚构参数。
- 做一次基本检查，排除裁切、明显额外部件和伪透明背景。沿用已认可参考，不增加无依据的审批环节。

## 2. Meshy 生成与母版归档

读 [Meshy 调用与交付](references/meshy-generation.md)，把所选参考作为 image-to-3D 输入，启用 texture 和 PBR。在任务范围内提交一次，保存 task ID，持续查询并下载。恢复中断任务先查已有 task ID，避免重复付费。API 失败不自动改走 Blender 重建。

凭据按当前用户授权使用；指定 GuestSafe 时用其 CLI，不把 token 写入技能、参数记录或版本管理。

将原始 GLB、服务返回的纹理、预览和参数保存到 `.cache/prototype-3d/<asset>/<version>/master/`；已有 `hifi` 缓存可继续只读使用，不为目录统一而搬动原件。记录 SHA-256、面数、文件字节数、纹理尺寸。母版不是游戏默认加载档；不为保留母版而追求额外高质量生成或另付费重生成。

## 3. 默认优化成约 3 万面游戏档

在同版本目录的 `runtime/` 输出约 **30,000 个三角面** 的 GLB；以全场景实际渲染几何总量计数，不把“顶点数”当面数，也不默认给每个 mesh 各分配 3 万面。先读 [GLB 瘦身与 Canvas 接入](references/runtime-optimization.md)。

- 将约 3 万面作为默认起点，结合游戏实际显示尺寸检查轮廓、炮管、薄片、人物肢体、建筑部件与材质接缝。小资产可以更少；若有明显损伤，保留失败候选，说明原因，再选择有依据的较高预算。不要把每个资产强制凑成同一面数。
- 先减少几何，默认保留原贴图，正确处理 UV、法线与切线。是否压缩贴图另按文件占比和对比结果决定，不把减面与降贴图混为一个不可分辨的操作。
- 优先用可复现的本地简化工具；压缩格式以实际加载链路支持为准。普通自包含 GLB 可作为兼容交付档；Draco、Meshopt、WebP 是经过真实解码验证后可选的分发档。
- 保留母版、优化配方、工具版本、输入／输出哈希与测量记录。减面不可逆；“可恢复”指从母版重新导出，不能声称从 3 万面还原高模。
- 验证优化文件真实可读、材质／贴图完整、实际面数和体积；至少在统一视角、比例和灯光下检查优化前后。可以用已存在的 GLB 查看器，不默认启动 Blender 做手工重建或无止境的视觉迭代。

默认完成条件：可读取的母版归档 + 已验证的轻量 GLB + 简短指标／复现记录。只下载最高面数服务输出不算完成优化交付。若优化工具不可用或无法达到可接受画质，明确报告当前状态，不把未优化母版冒充完成品。

## 4. 需要游戏内效果时：沿用 Canvas 2D

主游戏使用 `src/renderer.ts` 的 **Canvas 2D `BattlefieldRenderer`**。`prototypes/3d/` 和 GLB 查看器中的 Three.js 是独立工具，不是主游戏引擎。

用户要求游戏内预览或接入时，把优化 GLB 预渲染成透明 PNG 精灵／朝向图集，再交给现有 `Assets`、`GameEngine` 和 `BattlefieldRenderer`。沿用原投影、选择、遮挡与移动逻辑，只为高清源图必要地调整采样密度、逻辑显示尺寸和锚点。不要把另建 Three.js 战场描述为主引擎验收。

使用仓库 `npm run viewer:glb`，从查看器进入 **Canvas 2D 战场**。该模式当前展示已烘焙的四种样本；新 GLB 需要先出图并登记精灵映射，不能声称任意导入文件会自动变成游戏素材。细节见优化参考。

## 交付与 Blender 边界

提供轻量 GLB 作为首要入口，标明母版归档位置、实际面数、字节数、贴图与压缩格式。用户已允许将自制运行素材纳入仓库：经验证的轻量 GLB、高清精灵和生成清单放在 `assets/hd/`，按任务范围提交。高模母版、下载包及原版提取／转换素材继续留在被忽略的缓存目录。不把原版 SHP/VXL/TMP 或其直接转换图集混入自制素材目录；本地提交不代表授权推送或公开发布。

静态模型不等于完整游戏资产：多朝向不是走路、开火、死亡动画，单图生成背面仍是推断。不要声称自动完成绑定、独立炮塔或损毁状态。

用户要求“打开 Blender 让我看”时，将指定 GLB 导入 Blender，打包贴图并另存 `.blend`，供用户手动审阅。仅在用户要求手工重建、编辑或复现旧电厂时读取 [历史 Blender 流程](references/blender-reconstruction.md) 与 [电厂实例](references/powerplant-example.md)。运行 Blender 的约束见 [执行方式](references/blender-reconstruction.md#执行方式与版本)。
