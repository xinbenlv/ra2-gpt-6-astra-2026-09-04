# 历史可选流程：Blender 重建与比较

仅在用户明确要求手工重建、编辑或复现历史结果时使用。默认流程见 [SKILL.md](../SKILL.md)：内置 ImageGen → Meshy 生成带贴图的 3D → 下载。用户只要求打开成品时，仅需下述执行约束，不需要执行重建和比较步骤。

## 执行方式与版本

在仓库中定位已有 Blender，再检查实际版本与 `bpy` 能力；工作版本记录在产物中。电厂实例曾用官方 Blender 5.2.1 LTS，这只是已验证环境，不代表必须安装这一版，也不是与某个模型绑定的特殊版本。

### 沙箱外执行要求

用户已明确要求：以后运行 Blender 建模或渲染均在沙箱外执行，包括后台 Python 脚本、烘焙和渲染。Codex 的 `exec_command` 调用应设置 `sandbox_permissions: "require_escalated"`，并提供说明本次建模或渲染用途的 `justification`；仍遵循工具审批机制。不要先在沙箱内启动 Blender 来探测是否可用。GUI 优先通过 macOS 正常启动应用。

2026-09-06 在本机 Apple M5 Max、macOS 26.6.2、原生 arm64 Blender 5.2.1 LTS 上做过对照：同一可执行文件和以下完全相同的空场景命令，沙箱内退出码为 139，沙箱外打印 `DIAG_STARTUP_OK` 后正常退出（退出码 0）。

```sh
.cache/blender/Blender.app/Contents/MacOS/Blender --background --factory-startup --python-expr "import bpy; print('DIAG_STARTUP_OK', bpy.app.version_string)"
```

沙箱内堆栈与当日 GUI 崩溃报告一致：`GPU_backend_type_selection_detect()` → `MTLBackend::metal_is_supported()` → `supports_barycentric_whitelist()` → `_platform_strstr`，发生空指针访问。该对照确认沙箱环境触发此崩溃路径；具体被限制的系统访问尚未定位，不应断言 GPU 完全不可用。无需据此重装 Blender、切换架构或修改模型；遇到同类崩溃先检查是否误在沙箱内执行。

优先用 Python 创建可命名、可编辑的对象和材质，并在后台渲染。UI 适合观察/人工调整；连接失败时先核对已运行实例。不要把“UI 工具没有连上”解释成“Blender 没启动”。素材制作不要求启动 Three.js 或服务器。

## 先解投影，再改尺寸

1. 从图中多组平行边估计轴方向、俯角、画幅比例。区分正交/轴测与透视；不能让本应平行的边朝消失点收敛。
2. 固定相机类型、方位/俯角、目标点、正交宽度、分辨率、像素比例和位移。把相机记录与资产绑定。
3. 在相同画幅里选覆盖全物体的定位点和轮廓，不只选两个容易对齐的屋顶。先调整体块、再细化局部结构。

本电厂边斜率约 ±0.5，采用方位角 45°、俯角 30°，属于从图像拟合的假设，不是 EA 相机元数据。它也不是俯角 45°的真正等角投影。下一资产需重新测量。

对于正交宽度 `S`、画幅 `W×H`、方形像素、水平 sensor fit：

```text
m = S / W
P(u,v,d) = C + right × (u - W/2) × m
              + up × (H/2 - v) × m + back × d
```

`C` 是选定比较平面的中心；`u,v` 为左上角原点的连续屏幕坐标。若索引表示像素格而非其中心，取 `u=i+0.5, v=j+0.5`。相机右、上、后向量需由真实相机旋转得到。

这能准确把参考放在与相机平行的世界平面上，**不能从单张图求出被遮挡部分的深度**。深度 `d` 是未观测自由度；根据结构、其他原厂帧/视角和合理装配推断。参考平面只用于比较，排除于最终建筑渲染和导出。

把原厂小图配准到高清图时，优先采用能解释其共同结构的统一比例与平移，记录残差。不要用非均匀拉伸或逐部件扭曲掩盖比例错误。背景不作为结构拟合依据。

## 建模顺序和结构约束

把大体块、屋顶/斜面、管道、基础、紧固件、球壳/机械主体和特效分开命名。参数化尺寸与位置，保留当前认可模型的独立快照。

先看整体轮廓和遮挡，再对每组组件比较位置、直径、长度、弯头半径、接口中心和开口朝向。不能认为“两块屋顶对齐了”就代表管道也对齐了。局部误差明确时修改对应部件，不重新挪整个相机来隐藏它。

对金属球等已确认的基本形状，检查真实三轴尺寸和顶点半径；附加搭接板、滚边和铆钉也要沿其表面。搭接板不等同于细线纬度网格。实体支撑需装配合理，不能为填空添加参考没有的巨大笼架或对角杆。

不要默认前后对称。电厂最终为两侧柜体各一个正面斜罩、背面平直，这是一条本例的用户修正；其他建筑按自己的证据决定。

## 依据用途决定材质

先解释物体是什么，再选择材质。电厂墙面按钢框内的耐火砖/砌块理解，斜罩是涂漆钢板，粗弯管是磨损镀层钢，电球是抛光金属导体。这些是重建解释，而非源码已证明的材质标签。

做旧分层：较大尺度积垢/氧化，边缘掉漆，局部划伤/细小蚀点；接头和底脚积油，竖面有沿重力方向的流痕。不要让整栋建筑拥有同一种随机噪声、相同磨损尺度或均匀粗糙度。

- 管道沿真实中心线展开，UV 的两个方向分别是周长与行程长度，划痕应随弯头转向。
- 斜面沿板材局部坐标展开，避免用厚度轴映射表面；墙面沿竖直面展开。
- 非无缝 atlas 的 FRACT 重复会留下接缝。球冠不要把 UV 零点/经度极点放在醒目的冠顶；用单块连续纹理覆盖冠部，保留 tile 内边距。
- 金属粗糙度要保留连续反射。不要靠粗糙石质凹凸掩盖错误的光源形状或球壳法线。
- 较大曲面检查法线方向、接缝处平滑和极点。几何错误、UV 接缝与灯光反射需分别诊断。
- 不将完整参考图投影到建筑上充当纹理；这会在一个角度假装吻合，转动后失效。生成纹理只承担其声明的材质通道。

## 灯光与特效

材质和灯光会共同改变颜色。根据球壳反射位置和形状调整真实光源，再评估金属材质；矩形反光板可能造成不合参考的菱形白斑。一次集中调整一个问题组，保留前后图确认结果。

若资产有放电/烟火等动态效果，把固体和特效分开。电球通过反射受蓝紫光照，不靠整壳自发光变成塑料能量球。

电弧用绑定真实表面的发射点、实际接地块/导轨接收点和主干分支构成。大尺度路径有弯曲，细尺度有不规则扰动，粗细与末端渐细；过度平滑像软绳，采样太粗又像图标闪电。合流需落在另一主干的真实 3D 点，不能只在屏幕上相交。增大发光强度可能经色调映射变白，不能简单把“更蓝”等同于“更亮”。

静态 PNG 只证明该帧。若任务要求动画，再验证多个时刻的路径、反光、节奏和实体稳定性；浏览器运行时另做检查，不继承旧版本的验收结果。

## 比较与误差

实际渲染到参考尺寸或更高的等比例分辨率，保持同一画幅、相机和显示变换。不要用旧 PNG 放大来宣称提高了渲染清晰度。检查整图和重要局部，必要时额外渲染背面验证模型完整性。

对定位点 `i`，令 `dx,dy` 为屏幕误差，`r_i = sqrt(dx_i²+dy_i²)`：报告每点距离、平均距离、`sqrt(mean(r_i²))` 和最大/高分位误差。方向信息另列。左偏 5、右偏 5 的平均距离和 RMS 都是 5，平方误差和是 50；有符号平均为 0 不能用于相似度判断。

分别评价：

| 方面 | 有用证据 | 局限 |
| --- | --- | --- |
| 结构 | 覆盖轮廓与部件的定位点、实际开口/遮挡；必要时算轮廓距离或 IoU | 少数点对齐不能证明全图结构一致 |
| 表面与光照 | 固定建筑区域所有像素的 RGB MAE/RMSE、绝对差异高分位、局部细节观察 | 颜色差单位是 0–255 色值，不是像素位移；纹理相位不同也会增大误差 |
| 特效 | 起止位置、分支形态、光晕和多个时刻 | 一张好看的静帧不是动画验收 |

先对每个像素/通道取绝对值或平方，再汇总。避免大片棋盘背景稀释结果，也不要只挑容易吻合的区域。参考和区域定义保持固定；需要改变时记录版本并重新计算前后数据。

既有电厂 dense audit 在内存中把 2× 渲染按 2×2 平均到参考网格，不改写图片；该测量必须辅以原始高分辨率观察。报告变好和变差的区域，不换算成虚构的整体百分比。用户已认可的视觉结果应作为后续基准保留，数值不是替用户重新审批的工具。

## 可复查的交付

保存可编辑 authoring 文件；另存带实际相机、采样、尺寸、背景/合成器的 review 文件，打包用到的图片。交付真实 PNG、对应 `.blend`、输入来源/提示词/相机参数及版本信息。重新打开 review 检查材质是否完整，并确认 PNG 对应的模型版本；先做这些检查，再更新“当前版”文件名。

除非另有任务要求，直接展示本地渲染，不做网页包装或发布。运行时导出应在视觉结果稳定后，另行处理烘焙、纹理尺寸、LOD/性能和动态效果。
