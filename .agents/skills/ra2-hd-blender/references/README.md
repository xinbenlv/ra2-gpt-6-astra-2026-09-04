# RA2 高清资产参考文档

按任务读取对应流程。生成、优化与动态制作共用资产身份和留存规则；谭雅、电厂为实例，不是所有单位的参数模板。

```text
../SKILL.md
  -> source-to-hd.md -> meshy-generation.md -> runtime-optimization.md
  -> animation-and-team-colors.md -> direction-mapping.md
                                 -> skeletal-motion.md
                                 -> tanya-motion-example.md
  -> blender-reconstruction.md -> powerplant-example.md
                               -> powerplant-*.txt / powerplant-inputs.json
```

- `source-to-hd.md`：真实源图、通用参考提示词和输入记录。
- `meshy-generation.md`：生成任务、恢复和文件检查。
- `runtime-optimization.md`：预算、贴图、Canvas 投影和留存边界。
- `animation-and-team-colors.md`：步兵／机械分类、服装选区与换色、同地图循环验收。
- `direction-mapping.md`：前向轴证据、移动／攻击行为、八方向与错误偏移回归。
- `skeletal-motion.md`：逐源帧姿势与持物证据、骨骼适配、插值和计时验证。
- `tanya-motion-example.md`：首版基线、匍匐试验的复现入口、覆盖与迁移参数。
- `blender-reconstruction.md`、`powerplant-example.md` 及电厂提示词／清单：按需的历史手工重建记录，不覆盖当前默认流程。
